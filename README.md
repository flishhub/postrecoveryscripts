

# Post-Recovery Scripts

This repository contains modular PowerShell scripts designed to automate and standardize post-recovery tasks across Windows systems. Ideal for use after ransomware events, system restores, or disaster recovery operations.

## 🛠️ Scripts Included

- **DNSupdate.ps1**  
  Updates DNS client settings for restored systems.

- **PRTemplate.ps1**  
  Template for post-recovery automation: service restarts, GPO reapplication, malware scans, and cleanup.
